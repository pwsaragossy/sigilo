Enrolment — the key that stays yours

Spending inside the confidential pool means proving membership in the allow-list, and that proof is built from a secret only this holder's key can derive. The issuer never holds it. So enrolment is something the holder consents to — and it is checkable: the leaf the policy gate enrolled should be the one this wallet derives.
